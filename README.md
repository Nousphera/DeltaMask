# DeltaMask

**Communication-efficient federated fine-tuning of vision foundation models.**

[Paper](https://doi.org/10.1109/BigData62323.2024.10825398) · [Author manuscript](https://research.tue.nl/files/349909071/2024337517.pdf) · [Preprint](https://arxiv.org/abs/2311.17299) · [Provenance](PROVENANCE.md)

DeltaMask learns stochastic masks over pretrained models and compresses client updates using probabilistic filters. The method targets the communication cost of adapting foundation models across distributed clients.

## Repository status

This is a project reference repository, copied from FederatedML with its history preserved. The inherited repository contains a README and ignore rules; it does not contain implementation code, datasets, checkpoints, or an executable environment.

The paper describes the method and experiments. No reproduction commands or independently verified results are provided here.
